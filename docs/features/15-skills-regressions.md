# 15 — Skills + regression defenses

**Snapshot date:** 2026-09-01

The app carries a long list of load-bearing fixes. The default failure mode is: fix a new bug by unknowingly reverting one of these. This document + the skills + the hooks + the locked paths together break that loop.

## Project skills

Five project-specific skills at `.claude/skills/`:

| Skill | Load when |
|---|---|
| `pdf-editor-architecture` | Editing anything under editor folders (`lib/client/pdf-editor/**`, `lib/client/hooks/pdf-editor/**`, `components/sections/pdf-editor/**`) |
| `auth-flow-guardian` | Editing any file in the 21-step auth + paywall + export chain |
| `regression-forensics` | User reports a bug that used to work / says a fix reverted / "broken again" |
| `pre-push-guardian` | About to push, open PR, merge, or claim ready-to-ship |
| `memory-snapshotter` | Wrapping up a session, PreCompact hook fires, or a new preference / decision / root cause emerges worth persisting |

Skills are stored at:
```
.claude/skills/<skill-name>/SKILL.md
```

## Hooks

`.claude/hooks/` — pre-tool / event hooks configured in `.claude/settings.json`.

| Hook | Fires on | Purpose |
|---|---|---|
| `check-locked-paths.cjs` | PreToolUse (Edit/Write/MultiEdit/NotebookEdit) | Blocks edits to any path in `.claude/LOCKED_PATHS`. Bypass: `export CLAUDE_UNLOCK_PATHS=1`. See [`16-locked-paths.md`](./16-locked-paths.md). |
| `remind-memory-snapshot.cjs` | PreCompact + SessionEnd | Reminds to invoke `memory-snapshotter` before context is lost |

## Memory system

`.claude/memory/` — mirrors the user's personal auto-memory for this project so it travels with the repo. Index: `.claude/memory/MEMORY.md`.

Individual files hold:

- `user_role.md` — who the primary developer is
- `feedback_*.md` — behavioural rules (**Why** + **How to apply** lines)
- `project_*.md` — active work, decisions, in-flight bugs, external blockers
- `reference_*.md` — pointers to external systems / conventions

**Verify against current code** before acting on file:line citations — memory is point-in-time.

## Session specs

`.claude/specs/` — dated markdown files that capture the full evidence trail for non-trivial sessions (bugs diagnosed, decisions made, work shipped, work blocked). Ship with the codebase so any future developer has the story.

Current specs:

| Spec | Topic |
|---|---|
| `2026-07-30-signout-edit-persistence.md` | Signed-out edit → download → sign-in return flow — three bugs, full evidence |
| `2026-07-31-solidgate-audit.md` | Client Solidgate audit — charge-auth SDK migration, React Aria dismiss fix, hard-cancel webhook |
| `2026-08-03-apple-pay-diagnostic.md` | Apple Pay button not rendering — full stack green, blocked on Solidgate-side Apple verification |

New specs: `YYYY-MM-DD-<slug>.md`. Register in [`../../CLAUDE.md`](../../CLAUDE.md) §"Session specs" table.

## Repocards

`.repocards/` — pre-computed context folder generated by [repocards](https://www.npmjs.com/package/repocards).

- `AGENT_GUIDE.md` — routing guide (read first)
- `architecture.md` — top-level layout + hub files
- `entrypoints.md` — entrypoint list
- `index.json` — symbol → `file:line` map
- `graph.json` — imports_in / imports_out per file

Regenerate after code changes: `npx repocards index`.
