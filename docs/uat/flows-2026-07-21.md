## Fixes on this branch

1. **PDF→X convert routes now gate sign-in at upload.**
   `components/sections/new-landing/upload-workspace.tsx` — `requiresAuth` no longer excludes routes with `exportFormat`. Both directions of `/convert/*` now match Flow 1 exactly (Land → Sign-in → Conversion → Payment → Download).
2. **Race guard: fast drop before Clerk hydrates.**
   Same file — added `pendingDropRef` + a small effect that re-fires the drop once `authLoaded` flips true. Without this, a fast drop on a slow network could bypass both the sign-in and paywall gates for a signed-out visitor. This is a latent bug that ships to production once merged.
