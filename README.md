# PDFForge Frontend

Minimal Next.js + HeroUI frontend foundation for PDFForge.

## Current Scope

- Single-page app shell
- Theme-ready provider setup
- Shared `lib/` foundation for routes, logging, query setup, and client stores
- No auth, billing, PDF tool flows, or landing page design yet

## Stack

- Next.js App Router
- HeroUI v3
- Tailwind CSS v4
- TanStack Query
- Zustand
- next-themes

## Commands

```bash
bun install
bun run dev
```
